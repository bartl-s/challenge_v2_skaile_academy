# Drehbuch Demo-Video (2–3 Min, EIN Take, ungeschnitten)

**Demo-Lead:** die eigene alte Agentur-Seite (makeomatic.at) — echte Recherche,
aber keine fremden Kundendaten im öffentlichen Video.

**Vorbereitung (vor der Aufnahme):**
- Probelauf machen und Zeit stoppen. Dauert der volle Lauf über 3 Minuten:
  im Video den Markdown-Teil live laufen lassen und die fertige Seite aus dem
  Probelauf zeigen (ehrlich ansagen per Texteinblendung im Terminal-Kommentar).
- Bildschirm aufgeräumt: links Terminal mit Claude Code im Challenge-Repo,
  rechts Browser. Benachrichtigungen aus. Mac-Aufnahme: Cmd+Shift+5.

**Ablauf:**
- 0:00 README kurz im Bild: „AuditPilot — Problem: 30 Min Loom pro Lead."
- 0:20 Im Terminal eintippen: `/audit Makeomatic makeomatic.at`
- 0:30 Agent arbeitet sichtbar (Website lesen, Lücken finden). Nichts anfassen.
- 1:45 Fertiges Markdown-Audit öffnen, einmal durchscrollen.
- 2:15 Die daraus gebaute Audit-Seite im Browser zeigen: Hero, eine Lücke,
  Quick Win, Termin-Button.
- 2:45 Ende auf dem CTA-Button. Aufnahme stoppen. Kein Schnitt.

**Danach:** Als Loom oder YouTube unlisted hochladen, Link in README
(„Demo-Video") und in den Abgabe-Post (Vorlage in ABGABE.md) eintragen.
